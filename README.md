# fpga-arcade-platform

Tile-based arcade on the DE1-SoC: C++ game engine on embedded Linux (HPS) with a SystemVerilog graphics and sound pipeline (1024×768 VGA). Snake and Breakout, SDL2 PC backend. CS-326 project, NED University.
